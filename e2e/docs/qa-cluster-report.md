## 10. How to use the framework
```bash
cd e2e
npm ci
npx playwright install chromium
cp .env.example .env   # BASE_URL and test credentials
npm test               # whole suite (= bddgen && playwright test)
npx playwright test --grep @P1
npm run test:intermittent   # known intermittent bugs, N runs each
```

Turn on CI:
1. Commit `e2e/`, the workflow (`.github/workflows/qa-cluster-e2e.yml` or `e2e/ci/`), `qa-cluster.config.json` and the `.gitignore` lines the setup added — nothing else of the app.
2. Push to a branch the workflow listens to (main, the default branch, `qa/**`) or open a PR; the *Run workflow* button needs the file on the default branch.
3. Results: the job Summary and the `e2e-report-<id>` artifact.
